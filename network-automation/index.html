连接函数 core/connector.py

from netmiko import ConnectHandler
import paramiko
import yaml

# 修复 Python 3.10 与 ENSP 旧版 SSH 算法的兼容性
paramiko.Transport._preferred_kex = (
    'diffie-hellman-group1-sha1',
    'diffie-hellman-group14-sha1',
)

def load_devices():
    with open('config/devices.yaml', 'r', encoding='utf-8') as f:
        data = yaml.safe_load(f)
    return data.get('devices', [])

def connect_all_devices(devices):
    connections = []
    for device in devices:
        netmiko_params = {
            'device_type': device.get('device_type', 'huawei'),
            'host': device['host'],
            'username': device['username'],
            'password': device['password'],
            'port': device.get('port', 22),
        }
        conn = ConnectHandler(**netmiko_params)
        connections.append({
            'name': device.get('name'),
            'host': device.get('host'),
            'connection': conn
        })
    return connections

📋 核心功能二：批量执行任意命令

脚本 scripts/batch_command.py

def batch_send_command(connections, command):
    results = []
    for item in connections:
        conn = item['connection']
        name = item['name']
        output = conn.send_command(command)
        results.append({'name': name, 'output': output})
    return results

💾 核心功能三：批量备份配置

脚本 scripts/batch_backup.py

def backup_config(connections):
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    for item in connections:
        name = item['name']
        filename = f"{name}_{timestamp}.txt"
        output = conn.send_command('display current-configuration')
        with open(filename, 'w', encoding='utf-8') as f:
            f.write(output)

💡 关键技术要点

1. Python 3.10 与 ENSP 旧版 SSH 的兼容性

ENSP 默认使用较旧的 SSH 加密算法，Python 3.10 默认禁用了这些算法。需要在代码中手动启用：

paramiko.Transport._preferred_kex = (
    'diffie-hellman-group1-sha1',
    'diffie-hellman-group14-sha1',
)

2. Cloud 设备端口映射

ENSP 的 Cloud 设备使用 UDP 隧道转发数据，Python 脚本连接的是交换机的 SSH 端口（TCP 22），Cloud 会自动完成 UDP↔TCP 转换。

3. 端口互联必须划入同一 VLAN

VLANIF 接口要 UP，必须满足两个条件： - VLAN 已创建 - VLAN 下至少有一个物理端口处于 UP 状态
